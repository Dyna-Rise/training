CanvasでJavaScriptを学ぼう！

変数、条件分岐、繰り返しを使って、キャンバスに絵を描いてみよう。

問題1: 変数を使って図形を描こう

以下のキャンバスに、指定された位置と大きさで四角形を描いてみましょう。**変数を使って**、四角形の色や位置を設定してください。

ヒント

  • getContext('2d')で描画コンテキストを取得します。
  • ctx.fillStyle = "色";で塗りつぶしの色を設定します。
  • ctx.fillRect(x, y, 幅, 高さ);で四角形を描画します。
  • let 変数名 = 値;で変数を宣言できます。

問題2: 条件分岐で色を変えよう

以下のキャンバスに、ランダムな色の円を描いてみましょう。ただし、特定の条件（例: 円のX座標が中央より左なら赤、右なら青）で色を変えるように、**条件分岐（if文）**を使ってください。

ヒント

  • ctx.beginPath();で新しいパスを開始します。
  • ctx.arc(x, y, 半径, 開始角度, 終了角度);で円を描きます。（開始角度: 0, 終了角度: Math.PI * 2 で完全な円）
  • ctx.fill();で塗りつぶします。
  • Math.random()で0から1未満の乱数を生成できます。
  • if (条件) { ... } else { ... }で条件分岐ができます。

問題3: 繰り返しで星を描こう

以下のキャンバスに、複数の星をランダムな位置に描いてみましょう。**繰り返し（for文）**を使って、10個以上の星を描いてください。

ヒント

  • 星の形を描くのは少し複雑なので、まずは小さな四角形や円を「星」に見立てて描いてみましょう。
  • for (let i = 0; i < 回数; i++) { ... }で繰り返し処理ができます。
  • Math.floor(Math.random() * 最大値)で0から最大値未満の整数を生成できます。
